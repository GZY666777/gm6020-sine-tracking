# 接线与上电检查

## 1. 总体连接

```
                24 V 电源
             ┌──────┴──────┐
             │             │
        C 型开发板       GM6020
        CAN1_H ◄────────► CAN_H
        CAN1_L ◄────────► CAN_L
        GND    ◄────────► GND
        24V    ◄────────► 24V

        J-Link ── SWDIO / SWCLK / GND ── C 板 SWD 口

        USB-TTL ── RX ← PA9 (USART1_TX)
                 ── TX → PB7 (USART1_RX)
                 ── GND ─ GND
```

## 2. 引脚表

| C 板引脚 | 方向 | 连接到 | 备注 |
| --- | --- | --- | --- |
| PD0 | CAN1_RX | 电机 CAN_H/CAN_L（经收发器） | C 板内部已接 CAN 收发器，使用 CAN1 端口 |
| PD1 | CAN1_TX | 同上 | 1 Mbps |
| PA9 | USART1_TX | USB-TTL RX | 115200 8N1 |
| PB7 | USART1_RX | USB-TTL TX | 115200 8N1 |
| PA0 | KEY | 板载按键 | 低电平按下 |
| PH10/11/12 | LED B/G/R | 板载 RGB | 低电平点亮 |
| SWDIO/SWCLK/GND | 调试 | J-Link | 只接信号，不从 J-Link 取大电流 |

## 3. 24 V 供电的两种接法

### 方式 A：C 板 CAN 口自带 24 V（以丝印/原理图为准）

部分 C 板 CAN 接口的 4 芯中直接包含 24 V 和 GND，可以按官方线序直接给 GM6020 供电。

**上电前必须用万用表确认：**

1. 断电，测 CAN 口 24 V 与 GND 之间是否导通到电源输入；
2. 确认 24 V 不会接到 CAN_H/CAN_L；
3. 确认电机线序与板子丝印一致。

### 方式 B：电机 24 V 单独供电（推荐第一次使用）

- 24 V 电源同时给 C 板和电机供电；
- C 板与电机只连接 CAN_H、CAN_L、GND；
- 电源负极、C 板 GND、电机 GND 必须共地。

> 不要用 J-Link 的 3.3 V 给电机或开发板供电。

## 4. CAN 终端电阻

- 总线两端各 120 Ω；
- 节点多、线长时终端电阻更重要；
- 只有 C 板 + 一个 GM6020、线很短时，通常可以直接通信；如果出现间歇性丢帧，优先补 120 Ω 并检查共地。

## 5. 上电顺序

1. 断电，检查所有接线，特别是 24 V 与 CAN_H/CAN_L 是否接错；
2. 固定电机，确认转子可以自由转动；
3. 先给 C 板上电，串口应打印启动信息；
4. 再给电机 24 V 上电；
5. 观察串口是否出现 `# RUN`，电机是否开始正弦转动；
6. 如果异常，立即断电。

## 6. 首次测试建议

先把参数改小，确认方向正确后再恢复：

```c
#define SINE_SPEED_AMP_RPM   50.0f
#define SINE_POS_AMP_DEG     20.0f
```

确认：

- 正电压指令对应正转速；
- 位置模式目标增大时，角度按预期方向增大；
- 没有飞车、异响、过热。

如果方向相反，把 `MOTOR_SIGN` 改成 `-1`，不要只改目标符号。
